## 🚀 Getting Started

### 1. Enable GitHub Pages (if not already enabled)
- Go to Settings → Pages
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
- Save

### 2. Make Your First Commit
The files are ready to deploy. Just push and your site will be live in 1-2 minutes!

## ✏️ How to Customize

### Update Your Business Information
Edit `index.html` to change:
- Email address (line 157)
- Phone number (line 162)
- Service descriptions (lines 97-124)
- About section content (lines 149-153)

### Change Colors
Edit `styles.css` to customize:
- Main color: Change `#667eea` to your preferred color
- Accent color: Change `#764ba2` to your preferred color
- Background colors: Modify the gradient values

### Add More Content
You can easily add new sections by copying the structure of existing sections and following the same CSS class naming patterns.
